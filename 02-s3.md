
**Cross-Region Replication:** It means when we upload data to S3, AWS duplicates data on its own in the background in another S3.

**DataSync:** When we have on-premises data center. We want that our data should be stored in both places. In AWS storage and also in our data center.


**S3 Event Notification:** When we create or delete object in S3, Amazon S3 event notifications ek waqt mein sirf ek single destination (ya ek SQS, ya ek SNS, ya ek Lambda) par direct event bhej sakta hai. Aap S3 se multi-destination direct publish nahi kar sakte.


**S3 Transfer Acceleration:** If we have long distance and want to upload large data to S3, we use S3 Transfer Acceleration. We upload data in multiple parts. AWS stores the data in its Edge Locations and then move to S3.




Think:

> **Versioning = keep previous copies**
> **MFA Delete = extra authentication before permanently deleting versions**

### Exam shortcut 🧠

**Accidental S3 deletion → Versioning**

**Need stronger protection against permanent deletion → MFA Delete**

And don't confuse this with:

* **Signed URL** → controlled access
* **S3 storage classes** → cost/storage optimization
* **IAM policies** → permissions/access control

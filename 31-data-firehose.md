### 🎯 What is being tested?

**Streaming data → destinations**

### ✅ Correct answer

**Amazon Data Firehose**

### 🔑 Key concept

**Amazon Data Firehose** captures **streaming data**, can transform it, and delivers it to destinations such as:

* **Amazon S3**
* **Amazon OpenSearch Service**
* **Splunk**

Flow:

```text
Smart Sensors
     ↓
Data Firehose
     ↓
Transform
     ↓
S3 / OpenSearch / Splunk
```

**Streaming data + capture/transform/load + S3/OpenSearch/Splunk → Data Firehose.**

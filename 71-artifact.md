### AWS Artifact Kya Hai? 📄

**AWS Artifact** AWS ka ek free, central self-service portal hai jahan se aapko AWS ke official **compliance reports** aur **agreements** milte hain.

Jab kisi company ka audit hota hai (ya ISO / PCI-DSS certification chahiye hoti hai), toh auditors puchte hain: *"Kya AWS cloud ka infrastructure secure aur compliant hai?"* Iska proof dene ke liye aap AWS Artifact ka use karte hain.

---

### Iske 2 Main Portions Hotay Hain 🛠️

1. **AWS Artifact Reports:**
* Yahan se aap AWS ke third-party audit reports download karte hain.
* **Examples:** SOC 1/2/3 reports, PCI-DSS (payment card industry compliance), ISO 27001 certifications.


2. **AWS Artifact Agreements:**
* Yahan aap AWS ke saath legal compliance agreements accept ya manage karte hain.
* **Example:** HIPAA Business Associate Addendum (BAA) — agar aap healthcare data process kar rahe hain.



---

### Exam Keyword Memory Trick 💡

* **"Compliance Reports / Agreements / ISO / SOC / PCI-DSS Audit Proof"** $\rightarrow$ **AWS Artifact**
* **"Vulnerability Scanning in EC2/Lambda"** $\rightarrow$ **Amazon Inspector**
* **"Security Best Practices / Benchmarks Monitoring"** $\rightarrow$ **AWS Security Hub**
